# FPS+ 1.0

Приложение для управления системной разблокировкой генерации кадров через Shizuku без root. Пользователь подтвердил работу команды на REDMAGIC 11S Pro (nubia NX809J, REDMAGIC OS 11.5.8MR1_EA, Android 16). Работа на других устройствах и прошивках не гарантируется. Проект не связан с REDMAGIC и Shizuku.

## Установка и настройка

1. Установите [Shizuku](https://shizuku.rikka.app/download/) и APK. Для APK вне магазина может потребоваться разрешить установку из выбранного источника. Обновление существующей установки возможно только при совпадении ключа подписи APK; перед удалением старой установки учтите, что локальные данные будут удалены.
2. Включите параметры разработчика и беспроводную отладку Android. Выполните сопряжение и запустите Shizuku по инструкции приложения. На Android 11 и новее компьютер не нужен. После перезагрузки Shizuku без root обычно нужно запустить заново.
3. При первом открытии выберите язык интерфейса: English (выбран по умолчанию), русский, español, Deutsch или 日本語. Язык можно изменить позднее кнопкой Language / «Язык» на главном экране. Затем предоставьте доступ Shizuku. В карточке подключения доступны кнопки для [скачивания Shizuku](https://shizuku.rikka.app/download/) с официального сайта и перехода к официальной инструкции. Требуется служба с ADB Shell UID 2000. Если запрос был запрещён без повторного показа, разрешите доступ в Shizuku.
4. Включите разблокировку кнопкой. Приложение повторно прочитает свойство и сообщит результат. Откройте встроенную инструкцию для дальнейших шагов в игре.

## Игры и интерполяция

Приложение локально ищет доступные для запуска игры, отмеченные Android как игры, и известные игровые инструменты GameHub, Winlator и DroidDeck. Первые три найденных отображаются на главном экране, остальные доступны через «Все игры». Порядок приоритета: GameHub, Winlator, DroidDeck, Roblox, Minecraft, затем остальные по названию. Список обновляется при возвращении в приложение. Определение использует категорию Android, известные пакеты и названия; система может не классифицировать некоторые игры или сборки. Чтобы добавить пропущенную игру, нажмите «Добавить игру», затем при необходимости «Показать другие приложения» и выберите её вручную. Кнопка «Версия» на карточке GameHub позволяет выбрать установленный вариант. Автоматически обычные приложения в библиотеку не добавляются. Ранее добавленные вручную игры и отметки сохраняются при обновлении. Системные служебные приложения отфильтрованы, а Android может ограничивать видимость в разных профилях. Наличие игры в списке не гарантирует поддержку генерации кадров.

Приложение проверяет системное свойство, но **не определяет автоматически фактическую интерполяцию**. Отметки «работает» и «не работает» — исключительно результат проверки пользователя и сохраняются отдельно по пакету. Наличие запускаемой активности не гарантирует успешный запуск игры.

Приложение использует только `vendor.gpp.allgame.enable`: `1` — включение системной разблокировки, `0` — предполагаемое выключение. Результат записи всегда перечитывается. Первое значение перед изменением сохраняется локально: если оно `0` или `1`, его можно восстановить кнопкой. Пустое и отсутствующее свойство невозможно различить или удалить через этот механизм; `0` не является точным восстановлением отсутствия. Неподдерживаемые первоначальные значения не записываются обратно. После перезагрузки при возвращении в приложение может быть предложено восстановить сброшенное значение, но фоновая запись не выполняется. Изменение строки сборки вызывает предупреждение о возможной несовместимости.

При возврате из встроенной инструкции или полного списка жест «Назад» возвращает на прежнее место главного экрана. На самом главном экране жест не закрывает приложение.

Виджет показывает последнее прочитанное значение, которое может устареть. Нажатие открывает приложение, выполняет новое чтение и переключает значение при доступном Shizuku. Если служба или разрешение недоступны, включите их и повторите нажатие.

## Сборка

Откройте проект в Android Studio с JDK 17 или новее и установите Android SDK Platform 36 и Build Tools 36.0.0. Для тестовой сборки выполните `./gradlew assembleDebug`. Релизный APK собирается командой `./gradlew assembleRelease`. Для подписи задайте переменные `FPSPLUS_KEYSTORE` (путь к закрытому хранилищу), `FPSPLUS_KEY_ALIAS` и `FPSPLUS_KEY_PASSWORD` (один пароль для хранилища и ключа). Без них Gradle создаёт неподписанный release APK. Закрытый ключ и пароль не входят в репозиторий. Для обновления опубликованного APK необходимо подписывать все будущие версии тем же ключом. Тестовый APK 1.4 подписан другим ключом, поэтому Android не установит релиз поверх него; удаление тестовой версии удалит её локальные данные.

## Технические детали и графика

Compose, Material 3 и официальный Shizuku API/provider 13.1.5. Команды `/system/bin/getprop` и `/system/bin/setprop` выполняются в Shizuku UserService с проверкой UID 2000; без root, собственного ADB-сервера и скрытых привилегий. Приложение не запрашивает сетевое разрешение, не содержит рекламы или аналитики, не отправляет диагностические данные. Диагностика копируется только по нажатию. Данные игр и отметок хранятся локально. Список установленных приложений используется только на устройстве и никуда не отправляется; разрешение на доступ ко всем пакетам не запрашивается.

Значок FPS+ с английской надписью FPS нарисован для этого проекта как векторный ресурс; графика интерфейса и схемы шагов созданы средствами Compose; сторонние изображения и логотипы не используются. Применяются системные шрифты и символы. Библиотеки распространяются на условиях их собственных лицензий (AndroidX и Shizuku API — Apache License 2.0). Схемы игровой панели нарисованы средствами Compose по фотографиям пользователя; оригинальные фотографии в проект не включены. Схемы иллюстративны и не показывают текущее состояние телефона. Названия и расположение пунктов могут отличаться в других версиях прошивки.

Официальные источники: [Shizuku API](https://github.com/RikkaApps/Shizuku-API), [настройка Shizuku](https://shizuku.rikka.app/guide/setup/).


Релиз и исходники: [FPS+ на GitHub](https://github.com/Floppaputhon/FPS-plus).
